# Online Retail Sales Analysis

## Project Overview

This project is based on an online retail sales dataset. I analyzed the data to understand sales, revenue, customers, products, and country-wise performance.

I used **Python for data cleaning, SQL for data analysis, and Power BI for dashboard creation**.

## Objective

* Analyze sales and revenue performance.
* Understand revenue trends over time.
* Find the top-performing countries.
* Identify top products and customers.
* Create a Power BI dashboard to present the analysis.

## Tools Used

* **SQL** – Data analysis
* **Python (Pandas)** – Data cleaning
* **Power BI** – Dashboard and visualization
* **CSV** – Dataset

## Data Cleaning

I used Python and Pandas to prepare the data for analysis.

The main steps were:

* Checked missing values.
* Checked duplicate records.
* Removed cancelled transactions.
* Checked invalid quantities and prices.
* Created a revenue calculation using:

**Revenue = Quantity × Unit Price**

## SQL Analysis

I used SQL to analyze the cleaned data.

The analysis included:

* Revenue analysis
* Order analysis
* Customer analysis
* Product analysis
* Country-wise sales
* Monthly and yearly revenue trends
* CTEs
* GROUP BY and aggregations
* Window functions
* ROW_NUMBER()
* DENSE_RANK()
* LAG()
* NTILE()

## Power BI Dashboard

I created an interactive dashboard containing:

* Total Revenue
* Total Orders
* Total Customers
* Total Products
* Monthly Revenue Trend
* Top 10 Countries by Revenue
* Top 10 Products by Revenue
* Top 10 Customers by Revenue
* Revenue by Year
* Date Range Slicer

## Key Insights

The dashboard helps understand:

* Overall sales and revenue performance.
* Revenue changes over time.
* Countries generating the highest revenue.
* Products generating the most revenue.
* Customers contributing the most revenue.

## Project Outcome

This project helped me gain practical experience in **data cleaning, SQL analysis, and Power BI dashboard creation** using a real-world retail dataset.
